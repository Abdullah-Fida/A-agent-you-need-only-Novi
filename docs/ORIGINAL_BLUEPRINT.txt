1. SYSTEM HIERARCHY & ARCHITECTURE
--------------------------------------------------------------------------------
The ecosystem operates on a 3-tier hierarchy:
  [ Tier 1: User / Interface ] -> NOVI Voice Dashboard (React + Three.js Orb)
  [ Tier 2: Brain / Orchestration ] -> BotBrain (FastAPI + Async Event Loop)
  [ Tier 3: Subagents / Workers ] -> NewsAgent, ArticleAgent, StealthMarketer, Broadcaster


2. SUBAGENT POWERS & RESPONSIBILITIES
--------------------------------------------------------------------------------

A. NOVI (Voice & Web Dashboard)
   - Location: `omni_channel_bot/novi-dashboard`
   - Powers:
     * Listens to user voice commands using Web Speech API.
     * Renders 3D interactive orb reacting to status changes.
     * Executes front-end triggers for manually generating posts, toggling stealth mode, or checking status.
     * Displays real-time channel statistics and subscriber growth.

B. BotBrain (`core/brain.py`)
   - Powers:
     * Central dispatcher that controls all subagents.
     * Maintains active system state (posts generated today, current subscriber count, goal tracking).
     * Runs internal scheduler for auto-posting (6 posts/day target).
     * Manages global kill-switches and self-healing error handling.

C. NewsAgent / ContentEngine (`modules/content_engine.py` & `news_scraper.py`)
   - Powers:
     * Scrapes RSS feeds and news sites (Dawn, Geo, Tribune, Google News).
     * Filters out duplicate or previously posted headlines using Supabase.
     * Synthesizes short, high-impact Telegram posts (Title + Punchy Body + Hashtags).
     * Generates custom prompts and fetches 8K ultra-realistic AI images (Bing DALL-E 3 / Pollinations).
     * Packages text + image for delivery.

D. ArticleAgent (`modules/article_engine.py` - NEW)
   - Powers:
     * Receives raw news topic from NewsAgent.
     * Expands short news into massive 1,000+ word SEO-rich articles (H1, H2, Bullet points).
     * Generates 2-3 additional visual asset prompts for article layout.
     * Pushes long-form article directly to Supabase `articles` table for the Website.

E. TelegramBroadcaster (`modules/telegram_broadcaster.py`)
   - Powers:
     * Official Telegram Bot API connection (`python-telegram-bot`).
     * Auto-validates photo sizes (<10MB limit) and truncates captions (<1024 chars).
     * Pushes formatted HTML messages and images directly to public channel (@DailyPulsePK).
     * Fetches current subscriber counts for goal tracking.

F. StealthMarketer (`modules/stealth_marketer.py`)
   - Powers:
     * Runs on a separate BURNER phone account using Telethon User API.
     * Randomizes device fingerprints (Android 14, Samsung S24 Ultra, Pixel 8 Pro).
     * Zero-Trace: Scrapes competitor group active users directly into encrypted Supabase tables (never logs user IDs to console).
     * Drip Inviter: Invites max 2 users/day with randomized 30-90 min delays.
     * Smart Auto-Reply: Listens to competitor chats for keywords (crypto, rupee, tech) and posts helpful AI replies subtly mentioning @DailyPulsePK.

G. NotificationManager (`modules/notification_manager.py`)
   - Powers:
     * Sends non-intrusive HTML email alerts via Gmail SMTP.
     * Triggers notifications after successful posts or when emergency stop occurs.

H. TwitterBroadcaster (`modules/twitter_broadcaster.py`)
   - Powers:
     * Uses Tweepy API v2 to auto-post text updates.
     * Appends a promotional reply with the Telegram link to every tweet.
     * (Requires Twitter App to be linked to a Project in Developer Portal for Free Tier limits).

3. ENVIRONMENT CONFIGURATION & SECRETS
--------------------------------------------------------------------------------
The project relies on `.env` variables for authorization:
  - TELEGRAM_SESSION_STRING: Permanent session token for the main Telegram bot.
  - STEALTH_SESSION_STRING: Permanent session token for the Stealth Marketer burner phone.
  - SUPABASE_URL / SUPABASE_KEY: Database connection.
  - OPENROUTER_API_KEYS: LLM text generation.
  - BING_COOKIE: Used for DALL-E 3 image generation (Hugging Face is NOT used).


3. REQUEST & DATA FLOW
--------------------------------------------------------------------------------

Flow 1: Manual Voice Command
  1. User speaks: "NOVI, generate news post."
  2. Dashboard sends POST request to `/api/generate_post`.
  3. FastAPI server calls `brain.trigger_manual_post()`.
  4. Brain invokes `NewsAgent.produce_content_package()`.
  5. NewsAgent fetches news -> writes text -> generates AI image.
  6. Brain receives package and passes it to `TelegramBroadcaster.broadcast_post()`.
  7. Broadcaster posts to Channel and sends email notification via `NotificationManager`.

Flow 2: Automated Website Article Generation
  1. NewsAgent produces core story data.
  2. Brain routes story data to `ArticleAgent`.
  3. ArticleAgent generates full HTML article + 2 extra images.
  4. ArticleAgent saves record to Supabase `articles` table.
  5. Next.js website (`news_ecosystem_web`) fetches new article dynamically and updates `sitemap.xml`.
  6. NewsAgent appends website article link to Telegram caption.


4. ERROR HANDLING & SELF-HEALING MECHANICS
--------------------------------------------------------------------------------

A. FloodWait & Rate Limiting
   - If Telegram returns `FloodWaitError(x)` during broadcasting or stealth actions:
     * System catches exception, extracts wait duration `x`.
     * Logs warning and enters asynchronous sleep `await asyncio.sleep(x + 5)`.
     * Automatically retries action after sleep expires.

B. Emergency Kill-Switch (Stealth Security)
   - If StealthMarketer encounters critical auth errors (`SessionRevoked`, `PhoneNumberBanned`) or `PeerFloodError`:
     * Engages `self._emergency_stop = True`.
     * Disconnects Telethon client immediately.
     * Dispatches HIGH-PRIORITY emergency email alert to user.
     * Blocks all future stealth activations until manual dashboard reset.

C. Image Generation Fallbacks
   - Bing DALL-E 3 -> Pollinations.ai -> Text-only fallback.
   - If image generation fails or produces oversized binary (>10MB):
     * System logs warning and degrades gracefully to text-only telegram post, ensuring 0% missed schedules.

D. Content Deduplication
   - Hashes headlines and stores posted IDs in Supabase `posts` table.
   - Any scraped article matching a previously posted hash within 72 hours is automatically discarded.


5. NEXT.JS WEBSITE ARCHITECTURE (PHASE 2)
--------------------------------------------------------------------------------
  - Project Folder: `news_ecosystem_web`
  - Tech Stack: Next.js 14+ (App Router), TypeScript, Vanilla CSS (Glassmorphism), Supabase JS.
  - SEO Engine: Dynamic `sitemap.xml`, OpenGraph Meta Tags, Server-Side Rendering (SSR).
  - Cross-Platform Funnel: Direct links between Telegram channel and website articles.
