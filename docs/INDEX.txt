RULES FOR THIS FOLDER
--------------------------------------------------------------------------------
1. NEVER put a password, API key or token in these files. They are committed to
   git. Record WHERE a secret lives, never the secret. Secrets belong in Render
   env vars, and locally in render.env, which *.env keeps out of git.

2. Write down the reasoning, not just the decision. "Storage, not decor" is
   worth nothing in six months without the paragraph explaining why. Anything
   that was learned the hard way -- a wrong id, a cached list, a silent
   fallback -- goes in as a note so it is not rediscovered the expensive way.

3. Dates are absolute. "Last Tuesday" is useless later.

4. When something changes, update the file rather than adding a second one that
   contradicts the first.
